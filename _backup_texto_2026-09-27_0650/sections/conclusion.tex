\section{Conclusion}
\label{sec:conclusion}

We presented \sys, a framework that makes the relational requirements
of a question explicit in long-term memory retrieval. It combines
evidence-grounded planning with witness search over dated, source-linked
propositions, using verification and execution gaps to guide
replanning. A compact context of propositions and passage summaries
connects the resulting support to the final reader. The central
contribution is an explicit link between what retrieval seeks and
how the stored facts jointly support an answer, providing a basis
for inspecting and improving memory retrieval in language-model agents.
